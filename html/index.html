La semántica de las etiquetas HTML

El pilar fundamental de este lenguaje de marcas son las etiquetas. Sirven para identificar y estructurar el contenido dentro de un documento web. Lo que muchos olvidan a la hora de escribir un código html es la semántica de las etiquetas.

A continuación mencionaré alguno de los aspectos más importantes:

  • Hay que tener en cuenta tanto el contexto y la función de los distintos elementos de la web
  • Las etiquetas de HTML no son meros bloques para estructurar el contenido de nuestra web. Las etiquetas también tienen un significado semántico y hay que tenerlo en cuenta a la hora de utilizarlas.
  • Ayudan a la hora de implementar funcionalidaes adicionales. Nos facilitan mucho el trabajo si usamos todo su potencial.
  • Una buena selección de etiquetas mejora muchísimo la accesibilidad ya que facilitamos mucho la lectura del documento a personas con visibilidad reducida, sobretodo si hacemos un correcto uso de etiquetas como *header, nav, main, section...*
  • Saber usar las etiquetas también mejora cómo los buscadores posicionan nuestras webs porque lo valoran mucho.
